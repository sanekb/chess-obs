## Как использовать Админку

- зайти по логину и паролю (с компьютера или телефона)
- по итогу Турнира включить `Бонус` за топ при необходимости
- _опционально можно_:
  - `стрелочками` задать дату Титульника, результаты которого отображать
  - вручную тыкать на кнопку `Обновить` после каждой партии для моментального
    обновления результатов
  - скрыть/показать `Призовые` по соответствующей кнопке

## Как использовать Виджет

- добавить новый **браузерный источник** в OBS
- скопировать **ссылку на Виджет** из Админки, задать её источнику
- установить рекомендуемые размеры - **490x340**

## Доп. информация

- с началом каждого Титульника программа **автоматически** выставляет нужные
  настройки без участия Админки
- `Авто`обновление результатов происходит 1 раз в минуту в фоне (без участия
  Админки); выключается само через 2.5 часа после начала
